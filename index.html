Eerste keer? Zo regel je een Claude-key

Ethos Studio laat Claude het verhaal schrijven. Daarvoor heb je een persoonlijke sleutel (API-key) nodig — een soort inlogcode voor de AI. Even regelen, daarna werkt het jarenlang.

  1. Ga naar console.anthropic.com (open in een nieuw tabblad).
  2. Klik op Sign up en maak een gratis account. Je e-mailadres en een wachtwoord zijn genoeg.
  3. Log in. Klik in het menu links op API Keys.
  4. Klik op + Create Key. Geef een naam, bijvoorbeeld Ethos Studio.
  5. Er verschijnt een lange code die begint met sk-ant-... Klik op Copy (Kopiëren). Bewaar hem even — je ziet hem maar één keer.
  6. Kom terug naar deze pagina. Plak de code in het gele veld hieronder.
  7. Klik op Opslaan. Klaar! Je hoeft dit per browserbezoek maar één keer te doen.

💡 Eén gesprekskaart kost ongeveer 1 cent. Deel je key nooit met anderen — het is persoonlijk, zoals een wachtwoord.
